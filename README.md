# House Price Analysis & Prediction

## Project Overview
This project focuses on analyzing house sales data and building a Machine Learning model to predict house prices.

The project uses the Ames Housing dataset from Kaggle.

## Business Problem
The objective is to understand which factors influence house prices and develop a model that can estimate the sale price of a house based on its features.

## Dataset
- Training Dataset: 1,460 rows and 81 columns
- Testing Dataset: 1,459 rows and 80 columns
- Target Variable: SalePrice
- Location: Ames, Iowa, USA

Dataset Source:
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

## Limitations
- The dataset represents houses in Ames, Iowa, USA.
- Model predictions are estimates and not guaranteed market prices.
- The application is a portfolio demonstration, not a production real-estate valuation system.
